Privacy Policy

Last updated: November 8, 2026

ServerKampf Backup is a personal, non-commercial tool used by its administrator to back up and recover a privately hosted Minecraft server.

Information involved

Backup archives may include Minecraft world data, server configuration, player names and identifiers, player inventory/state, and associated mod data. The informational website does not accept logins, forms, or file uploads.

Google account authorization

The application uses rclone's Google Drive integration to access storage authorized by the administrator. OAuth tokens and related configuration are maintained on the administrator's own computer, not embedded in this public website or GitHub repository. Google handles account authentication.

Backup storage and security

The planned production configuration uses rclone encryption so backup file contents and filenames are encrypted locally before upload to the administrator's Google Drive. Server backups are not meant to be publicly shared. Access to decrypted backups is controlled by the administrator and by possession of the required decryption credentials.

Sharing, retention, and deletion

The administrator may transfer recovery snapshots privately to a trusted replacement host when necessary. Backup retention and deletion are managed through the administrator's local and Google Drive storage. Backup data is not sold or used for advertising.

Third-party services

This site is hosted on GitHub Pages, which may handle technical request data under GitHub's privacy statement. Google processes authorization and stored files according to Google's privacy policy.

Changes

This policy may be updated to reflect changes to the backup system. The latest version will be published at this URL.

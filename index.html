ServerKampf Backup

ServerKampf Backup is a personal, non-commercial utility for preserving and recovering a privately hosted Minecraft Java Edition server.

What the application does

The server administrator uses rclone and Google Drive to maintain recovery copies of the Minecraft world, mod configuration, and related server state. The intended backup configuration encrypts backup contents before upload.

Google sign-in is used only to authorize the administrator's own backup storage. This site is informational: it is not a login page, backup browser, or public file download.

For details about how the backup system handles information, read the Privacy Policy.
